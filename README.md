🚆 CoE Railway - Train Ticket Booking System
CoE Railway คือเว็บแอปพลิเคชันสำหรับจองตั๋วรถไฟออนไลน์ที่พัฒนาด้วย React + TypeScript และ NestJS (Mock) มุ่งเน้นการมอบประสบการณ์การใช้งานที่สะดวก รวดเร็ว และสวยงาม รองรับทั้งฝั่งผู้ใช้งาน (User) และผู้ดูแลระบบ (Admin)

✨ ฟีเจอร์หลัก (Key Features)
👤 สำหรับผู้ใช้งาน (User)
🔍 ค้นหาเที่ยวรถ (Search Trains): ค้นหาขบวนรถไฟโดยระบุต้นทาง, ปลายทาง, วันเดินทาง และจำนวนผู้โดยสาร

🕒 ดูตารางเดินรถเรียลไทม์: แสดงเวลาออก, เวลาถึง, ระยะเวลาเดินทาง และราคาตั๋วตามระยะทางจริง

💺 เลือกที่นั่ง (Seat Selection): ระบบเลือกที่นั่งแบบ Interactive เห็นผังที่นั่งชัดเจน แยกฝั่งทางเดินและหน้าต่าง

🎫 จัดการการจอง (My Tickets): ดูประวัติการจองตั๋ว พร้อมสถานะ (Confirmed/Cancelled)

🖨️ พิมพ์ตั๋ว (Print Ticket): สามารถกดพิมพ์ตั๋วโดยสารออกมาเป็นไฟล์ PDF หรือกระดาษได้ทันที (New!)

❌ ยกเลิกตั๋ว: ผู้ใช้สามารถกดยกเลิกตั๋วได้ด้วยตนเอง (หากยังไม่ถึงกำหนดเดินทาง)

🛡️ สำหรับผู้ดูแลระบบ (Admin)
📊 แดชบอร์ดสรุปผล (Dashboard): ดูยอดขายรวม, จำนวนตั๋วที่ขายแล้ว และจำนวนเที่ยวรถทั้งหมดในระบบ

➕ เพิ่มเที่ยวรถใหม่ (Add Train): ฟอร์มสำหรับเพิ่มขบวนรถใหม่ กำหนดชื่อ, เวลา, ประเภทรถ, และราคาได้ง่ายๆ

🗑️ จัดการเที่ยวรถ (Manage Trains): ตารางแสดงรายชื่อรถไฟทั้งหมด สามารถลบเที่ยวรถที่ไม่ต้องการออกจากระบบได้

📝 ตรวจสอบการจอง: ดูรายการจองล่าสุดของผู้ใช้ทุกคน (PNR, ชื่อผู้จอง, สถานะการชำระเงิน)

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
Frontend: React, TypeScript, Bootstrap 5, CSS Modules

Icons: React Icons (FontAwesome)

State Management: React Hooks (useState, useEffect) + LocalStorage (Mock Database)

Tools: Vite, Git, VS Code
